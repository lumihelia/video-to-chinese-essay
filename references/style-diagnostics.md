# 中文文风诊断：Video to Chinese Essay Profile

这份文件是 `video-to-chinese-essay` 的中文生成 profile。

它不是一套孤立发展的通用中文规则，而是一个**有版本来源的 vendored profile**：

```text
upstream: chinese-semantic-flow@0.2.0
sync-mode: vendored-profile
task: English long-form source → Chinese essay
```

## Scope

从 upstream 继承并在本任务中执行：

- core proposition first / B-first generation；
- forward semantic progression；
- contrast gate；
- 真实语义关系映射；
- evidence-bound specificity；
- retractable inference；
- 改写时保留原有立场与不确定性。

本文件另外保留英语长内容转中文文章时更具体的 local additions：

- 意合与动词链诊断；
- 名词化、被动语态、所有格与弱动词检查；
- generic `you` 的处理；
- 长文共享观察语气；
- transcript 引用准确性。

当 `chinese-semantic-flow` 的 minor / major 版本修改上述上游语义规则时，重新做 drift review。local additions 不因为 upstream 更新而自动删除。

---

## 0. 先确定 B，再生成

写一句话之前，先确定真正要表达的核心命题 B。

B 已经成立时，直接从 B 开始，让下一句继续它的因果、机制、后果、条件、时间变化或进一步理解。

**避免 contrast-first 的方法，是让 A 不成为默认起点。不要先生成 A，再把 A 删除。**

例如，真正要表达的是：

> 上下文设计决定了模型能看到什么，也影响它下一步能做什么。

就直接写这件事。不要先造出：

> 问题不在模型能力……

除非“模型能力是问题”已经真实存在于当前材料或前文。

---

## 1. Contrast Gate：处理真实存在的 A

以下结构本身不禁用：

- 不是 A，而是 B
- 不只是 A，更是 B
- 与其 A，不如 B
- 看似 A，实则 B
- A，但 / 可 / 却 / 不过 B

使用前检查：

1. A 是否真实存在于原 source、前文、明确可识别的读者预期，或与当前材料直接相关的公共误解？
2. 处理 A 是否增加理解？
3. B 是否本来就能独立成立？

A 不存在，或处理 A 没有信息功能时，从 B 生成。

### 合法 contrast

原讲者明确说：

> 很多人把这个问题归因于模型规模，但这里真正限制结果的是数据分布。

这里保留对照有信息价值，因为 A 本身就在 source 中。

### 无来源 contrast

source 只说明上下文设计的作用，却没有讨论“模型能力不足”。此时不要自行写：

> 这不是模型能力的问题，而是上下文设计的问题。

直接解释上下文设计如何影响输入、状态和下一步行为。

全文反复使用同一种“立 A → 推翻 A”动作时，也要检查是否已经形成修辞模板。

---

## 2. Forward Semantic Flow：让思想继续向前

两句话之间优先保持真实推进：

- 观察 → 解释
- 判断 → 原因
- 原因 → 机制
- 机制 → 后果
- 后果 → 二阶效应
- 现象 → 条件
- 当前结果 → 下一轮反馈
- 抽象判断 → source 中的具体案例

自检：

> 下一句是在继续当前命题，还是突然掉头修正一个前文没有出现的东西？

后者通常需要重写。

---

## 3. 意合优先，减少逻辑脚手架

英文经常靠连接词和从句显式标记逻辑。中文可以让语序、并置、动作和上下文承担更多关系。

警惕这些词连续承担段落骨架：

- 因此 / 所以
- 但是 / 然而 / 不过 / 可 / 却
- 由于……从而……
- 不仅……而且……
- 值得注意的是
- 更重要的是

这些词可以使用。判断标准是它们是否真的承担必要关系。

不要把一个明显的因果链拆成几句再用“因此”粘回去；能让动作本身推进时，让动作推进。

---

## 4. 用动词链，不让名词化接管句子

英语长内容常把动作名词化，再用关系词连接。中文重写时把动作还原出来。

警惕：

- ……的本质
- ……的体现
- ……的呈现
- ……的发生 / ……的提出 / ……的形成
- 一堆名词性短语靠“是”连接

翻译腔：

> 这种现象的本质，是用户在面对信息过载时所产生的一种认知防御机制的体现。

更自然：

> 信息一多，人会先筛掉一部分，再简化剩下的，最后干脆不看了。

检查主语和宾语位置是否被“……的……”打包成动作名词。能拆回动作短句时，优先拆开。

---

## 5. 主动语态与所有格经济

英文被动句不需要机械保留成中文“被”字句。

例如：

- `he was promoted` → `他升职了 / 他升为……`
- `the idea was not accepted` → `大家没有接受这个想法`

“被”本身可以自然使用；同一段大量出现且都来自 source 的被动语态时，检查是否只是批量直译。

所有格同理：

- `he raised his hand` → `他举起手`

不要因为英文写了 `his / her / their`，中文就逐次保留“他的 / 她的 / 他们的”。

---

## 6. 弱动词 + 抽象名词

警惕：

- 进行讨论 → 讨论
- 进行分析 → 分析
- 作出决定 → 决定
- 作出回应 → 回应
- 加以解决 → 解决
- 予以说明 → 说明

这些组合不是绝对错误。能用真正动词直接表达时，优先让动词承担动作。

---

## 7. Generic `you` 不自动变成「你」

英语里的 generic `you` 常表示一般人、使用者或某种情境中的人，不一定是在直接对读者说话。

优先使用：

- 自然省略主语；
- 人 / 人们；
- 使用者；
- 身处其中的人；
- 具体角色。

只有 source 或文章确实需要直接看向读者时，再使用「你」。

「我们」也只在确实存在共同观察位置时使用。不要为了制造亲近感反复把作者与读者强行绑成同一个主体。

---

## 8. 抽象判断必须回到 source

“底层逻辑、深层结构、系统性变化、认知框架、结构性问题、重塑、重构”等词只有在具体机制已经成立时才有价值。

每个重要抽象判断至少能回到一种锚点：

- source 中的明确说法；
- 具体案例；
- 产品 / 技术机制；
- 行为变化；
- 可以核对的 transcript 证据。

source 没有提供的事实不要为了“更具体”而补进去。

合理推断需要保持可撤回，不写成讲者的明确原话。

---

## 9. 目标语气

目标是一位中文作者认真处理完一段长内容之后，写给同样关心这个问题的人看的观察长文。

避免：

- 老师对学生的教学腔；
- 博主对粉丝的训导腔；
- 课程销售式营销腔；
- 每段都总结成金句的 AI 腔；
- 为了“像人”而故意制造口语填充或混乱。

作者可以有判断，但不能靠拔高 source 制造深度。

---

## 10. 引用必须可追溯

只有 transcript 中能找到明确原句时才使用引号。

无法确认逐字准确的内容用转述。翻译后的中文引语也要保持原意，不把普通表达加工成更锋利的“金句”。

引用服务于证据，不服务于装饰。

---

# 完稿自检

1. 真正成立的核心命题 B 是否在每个关键段落里清楚？
2. 有没有先默认生成 A，再删除或换壳？
3. 每一处 contrast 的 A 是否真实存在，而且处理它增加信息？
4. 后一句是否继续前一句，而不是频繁掉头纠正不存在的观点？
5. 是否靠连接词搭段落骨架？
6. 能否把名词化结构还原成动词链？
7. 被动语态和所有格是否来自英语机械迁移？
8. “进行 / 作出 / 加以 / 予以 + 抽象名词”是否可以恢复成直接动词？
9. generic `you` 是否被机械翻成「你」？
10. 「我们」是否真的有共同主体依据？
11. 每个抽象判断是否有 source 锚点？
12. 推断是否被写成讲者的明确说法？
13. 引号里的内容是否能回到 transcript？
14. 有没有为了制造深度、力度或金句而改变 source 的判断？
15. 整篇文章是否在中文里向前运动，而不是保留英语论证脚手架？
